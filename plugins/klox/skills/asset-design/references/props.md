# Props, products and functional states

Identify whether the object carries an action, recognition, evidence or brand promise. A recurring or plot-critical object needs a reusable design; ordinary set dressing can stay in the location. Ground story functions in the accepted material.

## Anchor and scale

Define silhouette, main dimensions or relative scale, material, distinguishing features and functional parts. Make a clean anchor on a plain background, with readable shape and unobstructed edges. Present the object on its own in production references; use explanatory boards for hand studies, rulers and scale comparisons.

For a product, preserve the supplied packaging and exact required logo/text. Preserve accepted brand facts and confirm proposed brand changes. Inspect required label text and repair it before accepting the reference.

For previs-backed interactions, pass approved dimensions and functional contact features in the description. Use prop Actors as geometric stand-ins and check the supported scene capabilities for the intended interaction. Reference design acceptance does not prove that the video model executes the contact. Furniture that belongs to a location's set moves in previs as a fixture prop that keeps its set reference for size and initial placement; a transform track then describes movement and tipping in world space. Review grasping, gravity and collision in the generated interaction. When exact contact matters, choose a suitable detail reference or coverage and review the generated interaction.

## States and interaction

Add only functional views needed by the action: open/closed, front/back, screen active, latch released, or a required interior. For reusable configurations use looks; a one-shot scratch, wet surface or temporary contents can be shot state. Represent a hand holding the object in the shot staging.

Derive state images from the selected object anchor. Preserve dimensions and construction across states. Check hinges, handles, closure orientation, compartments, thickness and the places where a hand must contact it. If an interaction needs precise contact, the storyboard must show it at a readable scale; review its execution in the generated video.

Keep an annotated mechanical diagram separate from clean references. Use detail crops to clarify established features.

## Review and handoff

Compare the object at the intended shot scale: can the viewer recognise it and read the feature that matters? Confirm that its size relative to a person is believable and that opened states still belong to the same object. Explain text that must be preserved or replaced in post.

Save the object as kind `other`, clean references in priority order, and explanatory boards in `designBoards`. A representative insert or contact keyframe can test practical use when requested; report video interaction as unverified until it is actually produced and reviewed.
