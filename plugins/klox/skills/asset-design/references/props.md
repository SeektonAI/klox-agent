# Props, products and functional states

Identify whether the object carries an action, recognition, evidence or brand promise. A recurring or plot-critical object needs a reusable design; ordinary set dressing can stay in the location. Do not add story functions that the source has not established.

## Anchor and scale

Define silhouette, main dimensions or relative scale, material, distinguishing features and functional parts. Make a clean anchor on a plain background, with readable shape and unobstructed edges. Keep hands and unrelated objects out of the production reference; put a ruler or scale comparison on an explanatory board when needed.

For a product, preserve the supplied packaging and exact required logo/text. Do not redesign brand facts without authorization. An attractive generated label is insufficient: inspect required text and repair it before using the image as a reference.

## States and interaction

Add only functional views needed by the action: open/closed, front/back, screen active, latch released, or a required interior. For reusable configurations use looks; a one-shot scratch, wet surface or temporary contents can be shot state. A hand holding the object is shot staging, not a new object identity.

Derive state images from the selected object anchor. Preserve dimensions and construction across states. Check hinges, handles, closure orientation, compartments, thickness and the places where a hand must contact it. If an interaction needs precise contact, the storyboard must show it at a readable scale; the prop sheet cannot guarantee video execution.

Keep an annotated mechanical diagram separate from clean references. A detail crop should clarify an actual feature, not invent additional parts.

## Review and handoff

Compare the object at the intended shot scale: can the viewer recognise it and read the feature that matters? Confirm that its size relative to a person is believable and that opened states still belong to the same object. Explain text that must be preserved or replaced in post.

Save the object as kind `other`, clean references tagged `other`, and explanatory boards in `designBoards`. A representative insert or contact keyframe can test practical use when requested; report video interaction as unverified until it is actually produced and reviewed.
